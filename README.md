# 🤖 Multi-Agent Automation System

A simple multi-agent collaboration system built with Python (asyncio).

## 🚀 Features

* Manager-Agent task allocation
* Worker-Agent execution
* Coordinator-Agent result aggregation
* Asynchronous message-based communication

## 🧠 Use Cases

* AI content automation
* Task orchestration systems
* Autonomous agent workflows

```bash
python main.py
```
